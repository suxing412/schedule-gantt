使用帮助

基本操作

• 拖动任务条 = 移动日期；拖动条两端 = 调整起止；拖拽中按 Esc 取消
• Shift + 点击任务条 = 多选（左侧行也可 Ctrl + 点击）；多选后可整体拖动 / 批量挪期 / 批量删除
• Ctrl + 从一个任务条拖到另一个 = 建立依赖连线
• 双击任务条 / 左侧行 = 编辑；双击时间轴空白 = 在该日期新建
• 右键任务或空白处 = 更多操作（子任务、复制、流程模式、删除）
• 左侧行首 ⠿ 拖动：放到目标行上/下边缘 = 排序（同级）；放到目标行中部（亮蓝框）= 挂为其子任务；拖动表头列边缘 = 调整列宽
• 「▦ 管线」= 顶层容器（Boss管线/马匹管线…），下面建功能模块与任务；管线始终在顶层
• 时间轴是完整日历：向左/向右一直滚动会自动延伸到过去和未来

快捷键

• CtrlZ 撤销　CtrlY 重做　CtrlF 搜索
• ↑↓ 选择任务　←→ 挪期一天（Shift = 7 天）
• Enter 编辑选中项 / 在弹窗内保存　Delete 删除选中
• Esc 关闭弹窗 / 取消多选 / 清除筛选　Shift + 滚轮 = 横向滚动

标识说明

• 颜色 = 任务职能（策划 / 美术 / 程序 / 技术策划 / 技术美术 / 动画），点击图例可按职能过滤；职能可在设置（齿轮按钮）里增删改名换色
• 任务可另标「阶段」（原型 / 正式化开发…），图例同样可按阶段过滤；阶段管理也在设置里
• 定位标（圆头白心）= 重要节点：占一行、可设依赖；在流程泳道内钉在行道上，可与任务条重叠（如 review 点）
• 流程泳道内的子父单收起为一整条（名字带 ⌄），鼠标悬停原地展开显露内部流程
• 依赖建议在同层级之间建立（推荐列表只给同级兄弟）；Ctrl 拖线跨层仍可用但会提醒
• ⚑ 旗子 = 里程碑：双击顶部日期栏在该日插旗，带贯穿全图的竖虚线，与任务自由重叠；点旗子编辑/删除
• 红色描边任务 = 关键路径；橙色 ⚠ = 开始日期早于其依赖的完成日期
• 父任务日期与进度由子任务自动汇总；流程模式把子项排在同一行

数据

• 自动保存到本地，打包版同时备份到 exe 同目录「排期数据.json」
• 「导出 / 导入」用 JSON 文件在同事间传递排期
