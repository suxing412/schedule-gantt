# schedule-gantt · 排期工具

> 甘特图排期工具：可独立运行的 Node.js 共享网页服务，也保留 Electron 桌面版。
> 快速录入任务、拖动调整日期、按职能着色、按管线组织、自动分析关键路径与日期冲突、一键导出 PNG 同步给同事。

设计哲学：**工具隐形**——每个界面元素都必须服务于"排期"这个动作本身；
色彩只有两种用途（职能归属、状态警示）；能在图上拖的就不进弹窗；撤销比拦截更符合心流。
参照 Things / Linear 的克制，详见 [PRODUCT.md](PRODUCT.md) 与 [DESIGN.md](DESIGN.md)。

## 功能

- **甘特图直接操纵**：拖动移动任务、两端拉伸改起止，日/周/月视图 + 今天线
- **职能着色**：策划 / 美术 / 程序 / 技术策划 / 技术美术 / 动画（可在设置中自定义）
- **管线分组**：按顶层管线（如 Boss 管线 / 坐骑管线）组织任务
- **阶段标记**：原型 / 正式化开发等进程阶段
- **关键路径与冲突分析**：自动高亮工期底线与日期打架的任务
- **PNG 导出**：导出图不需要解释就能被同事看懂
- **本地数据**：数据自动保存到本机；桌面版同时写入 `排期数据.json`，保留前一版备份，启动时读取同一排期最新的有效副本

## WorkBuddy 内置云部署

WorkBuddy 版本使用官方 Cloud SDK 调用数据库 RPC，保留「分享链接查看、昵称＋四位编辑码编辑」。编辑码哈希、编辑会话和限流计数保存在云端私有表；浏览器只能调用经过授权检查的业务函数。静态 Node 服务默认端口 `3000`，不保存排期数据，不需要数据库连接串或 service-role 密钥。

运行 `npm run release:workbuddy` 生成完整交付目录。部署方执行随包 SQL 迁移、注入平台 `publicConfig` 对应的公开配置，然后启动服务；前端 RPC 接入和数据库函数均已包含。完整步骤、平台验收及限流边界见 [WorkBuddy 部署说明](cloud/DEPLOYMENT.md)。现有本机 JSON 排期可在新建的云排期中通过导入迁移；原 Node 的 scrypt 哈希不会自动转成 bcrypt，应在新云排期设置编辑码。

## Node 服务与外部数据库部署

使用 Node.js 22 或更新版本，在项目目录运行 `npm start`，打开 http://localhost:3000。服务同时提供网页和 API，无第三方运行依赖。首次打开创建空白排期，获得独立分享链接；访客只读，填写昵称和四位编辑码后可编辑。

这条独立路线本地默认使用开发文件存储，生产需要另行实现外部数据库适配器并配置会话密钥，缺少配置时拒绝启动。WorkBuddy 内置云请使用上一节的专用交付，不使用这个通用适配器模板。详见 [Node 部署说明](DEPLOYMENT.md) 和 [外部数据库适配器契约](server/ADAPTER-CONTRACT.md)。

运行 `npm run release:web` 可生成独立的网页项目目录，不包含 Electron、依赖安装目录、凭据或本地排期数据。

## 快速开始

```bash
npm start          # 共享网页服务，默认 http://localhost:3000
npm run release:web # 生成独立网页交付目录
npm run start:workbuddy # WorkBuddy 云版本，需平台公开配置
npm run release:workbuddy # 生成含 RPC SQL 和官方 SDK 的部署交付目录
npm ci             # 可选：安装桌面开发依赖
npm run preview    # 当前源码的本地网页预览，无需安装依赖
npm run desktop    # Electron 桌面版开发运行
npm test           # 运行回归测试
npm run pack       # 打包独立文件夹
npm run dist       # 打包 exe（electron-builder）
```

或直接下载 [Releases](../../releases) 里的成品 zip，解压即用。

## 当前源码的网页预览

在项目目录运行 `node scripts/preview.cjs`，有 npm 时也可运行 `npm run preview`，然后在浏览器打开 [本地预览](http://127.0.0.1:5173)。预览服务使用 Node 内置功能，无需先安装依赖。修改源码后刷新页面即可查看；按 `Ctrl+C` 停止预览服务。预览中的排期保存在当前浏览器，可通过 JSON 导入、导出迁移。

当前源码支持独立拖动任务名、负责人、开始、结束、进度各列的边界，表格横向滚动时表头同步。工具栏「列与字段」可管理显示、顺序和自定义字段，支持多行文本、数字、日期、单选和勾选；字段改名保留已填写的值，隐藏保留数据，修改可撤销。双击任务填写字段，PNG 使用当前显示的列，JSON 保留完整字段数据。

列宽与左右面板比例独立：拖列头边界改变单列宽度，拖中线改变左右区域；双击列边界适应内容，双击中线恢复默认比例。名称列在空间允许时固定，过宽时随其他列滚动。通过「列设置」恢复默认列宽，点击「添加字段」创建属性。

「列与字段」还提供常用项快捷入口：优先级（高／中／低）、Owner（使用现有负责人列）、职能（显示现有职能列）、预计工时（小时）、预计工期（天）和多行备注。预计工期用于记录估值，不会自动调整排期日期。

这部分功能用于当前源码预览。已分发桌面包的用法以随包手册为准。

## 使用

见 [使用手册.md](使用手册.md)。

当前版本 **v1.4.5** 修复了保存与恢复、复制与撤销、依赖分析、流程展开与筛选、远期时间轴导航及 PNG 导出等问题，保留现有本地排期流程。开发版备份位于项目目录；打包版位于 exe 同目录，迁移时可连同 `排期数据.previous.json` 一起复制。启动会区分不同排期，其他排期的本机缓存不会覆盖便携文件；同一排期仍按副本版本读取较新的数据。
