# schedule-gantt · 排期工具

> 本地优先的极简甘特图排期工具（Electron 桌面应用）。
> 快速录入任务、拖动调整日期、按职能着色、按管线组织、自动分析关键路径与日期冲突、一键导出 PNG 同步给同事。

设计哲学：**工具隐形**——每个界面元素都必须服务于"排期"这个动作本身；
色彩只有两种用途（职能归属、状态警示）；能在图上拖的就不进弹窗；撤销比拦截更符合心流。
参照 Things / Linear 的克制，详见 [PRODUCT.md](PRODUCT.md) 与 [DESIGN.md](DESIGN.md)。

## 功能

- **甘特图直接操纵**：拖动移动任务、两端拉伸改起止，日/周/月视图 + 今天线
- **职能着色**：策划 / 美术 / 程序 / 技术策划 / 技术美术 / 动画（可在设置中自定义）
- **管线分组**：按顶层管线（如 Boss 管线 / 坐骑管线）组织任务
- **阶段标记**：原型 / 正式化开发等进程阶段
- **关键路径与冲突分析**：自动高亮工期底线与日期打架的任务
- **PNG 导出**：导出图不需要解释就能被同事看懂
- **本地数据**：无账号无云端，数据存本机（`排期数据.json` 备份在 exe 同目录）

## 快速开始

```bash
npm install
npm start          # 开发运行
npm run dist       # 打包 exe（electron-builder）
```

或直接下载 [Releases](../../releases) 里的成品 zip，解压即用。
