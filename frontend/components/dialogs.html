使用帮助

安排任务

  • 拖动任务条调整日期，拖动两端调整起止时间。拖拽中按 Esc 取消。
  • 双击任务条或左侧行编辑；双击时间轴空白处，在该日期新建任务。
  • Shift + 点击任务条可多选，左侧行也支持 Ctrl + 点击。多选后可整体拖动、批量挪期或删除。
  • 右键任务或空白处，可添加子任务、复制、切换流程模式或删除。
  • 拖动左侧行首把手：放在行的上下边缘为同级排序，放在行中部则设为子任务。
  • 管线是顶层容器，可在下面建立功能模块和任务。父任务的日期、进度由子任务自动汇总。

调整视图

  • 拖动中间分隔线调整左右比例，双击恢复默认比例。拖动列头边缘只调整该列，双击适应内容。
  • 两边可独立横向滚动，纵向滚动同步。名称列在空间足够时固定；「列与字段」可以管理列顺序、显示和自定义字段。
  • 点击职能或阶段筛选任务；名称和颜色可在「项目设置」中管理。
  • 时间轴会向左右自动延伸。Shift + 滚轮可横向滚动。
  • Alt + 滚轮以鼠标位置为中心等比缩放整图，日期格、行高、任务条和文字一起变化；点击百分比恢复 100%，日、周、月切换时间粒度并恢复比例。
  • 在「负责人高亮」中选择昵称可突出显示其任务；点击任务条或任务行固定显示完整上下游依赖链，点击其他任务切换，点击画布空白或「依赖链 ×」提示取消。
  • 流程模式把子项排在同一行，悬停在收起的子父任务上可展开内部流程。

依赖与关键日期

  • 按住 Ctrl 从前置任务拖线到后置任务，建立依赖。推荐同层级任务之间建立依赖。
  • 重要节点占一行并可设置依赖；在流程泳道内可与任务条重叠，用于标记验收等检查点。
  • 里程碑以旗子和贯穿时间轴的虚线标记。双击日期栏插入，点击旗子编辑或删除。
  • 红色描边表示关键路径；橙色警告表示开始日期早于前置任务完成日期。

保存与传递

数据自动保存在当前浏览器。桌面版同时备份到程序目录下的「排期数据.json」。使用导入、导出功能，通过 JSON 文件传递完整排期。

协作者

显示仍持有效编辑会话的协作者。昵称由使用者填写，同名会话会分别显示；并非实名认证。

    最近 60 秒收到活动信号视为在线。页面在前台时每 20 秒更新一次，退出或关闭页面后停止。
